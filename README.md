# Lakópark – portfólió 2

Erdei lakópark Hévíz és Keszthely között: látványtervek, jelölt helyszínrajz, madártávlati képek, perspektívák, stílustanulmányok, böngészőben forgatható 3D modell, 360°-os túrák és adatok.

- `index.html` – a weboldal (egy fájl, a képek az `assets/img` mappában)
- `modell.html` – a 3D modell nézegetője (three.js; a modell az `assets/3d` mappában, glTF/GLB)
- `Lakopark_portfolio_2.pdf` – nyomtatható / küldhető változat (32 oldal, 1920 × 1080)

Készült: Blender, D5 Render, Blender Cycles · 2026
